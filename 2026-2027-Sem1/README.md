# 2026-2027 Semester 1

This folder should work like a clean study desk, not a maze.

## Start here

Use one path only when studying:

`PROGRESS.md` -> subject master -> session note -> lab or open-book page if needed

That keeps each subject self-contained. You should not need to jump across `_shared/` files just to understand a session.

## One place per question

| If you need... | Open this file first | Why |
|---|---|---|
| What is done / missing this week? | `PROGRESS.md` | One dashboard across all four subjects |

| Fast exam lookup later | `openbook/` inside that subject | Derived after the notes exist |

## Study rule

Treat each subject folder as a standalone notebook:

- Start from the subject master.
- Read the session note for understanding.
- Open the lab only when the note tells you to build something.
- Use `_shared/` only as optional synthesis after the subject note is already clear.
