Problem Statement 
Module 1: Dataset and Embedding Preparation — 1 Marks 
Task 1: Corpus and Query Dataset Preparation — 0.5 Marks 
Select one publicly available text dataset suitable for semantic retrieval. And create: 
● A document corpus of at least 1,000 text passages 
● A query set of at least 50 queries 
● Relevance information for each query 
Students may use an existing dataset containing query-document relevance labels. 
Task 2: Embedding Generation and Pooling — 0.5 Marks 
Select two accessible encoder-based embedding models. Generate embeddings for 
the same corpus using both models. 
For each model, document: 
● Model name 
● Embedding dimension 
● Maximum/typical input length 
● Pooling strategy used 
● Approximate time required to generate the embeddings 
Explain why encoder models are appropriate for semantic representation and retrieval. 
Do this using atleast do different models and make a comparison study. 
Module 2: Similarity and Exact Retrieval — 3 Marks 
Task 3: Similarity Metric Comparison — 1.5 Marks 
1. For one selected embedding model, compare the following similarity measures: 
● Cosine similarity 
● Dot product 
● L2/Euclidean distance 
2. Select at least 20 query-document pairs and calculate the similarity/distance 
values. 
3. Analyse: 
1. Whether the ranking of documents changes across metrics 
2. Whether normalization affects the results 
3. Which metric appears most suitable for your selected embeddings 
The analysis should refer to the mathematical definition of the similarity measures 
rather than simply reporting library output. 
Task 4: Exact kNN Baseline — 1.5 Marks 
1. Implement an exact nearest-neighbor search baseline. 
2. For each query: 
● Generate the query embedding 
● Compare it against all document embeddings 
● Retrieve Top-5 documents 
3. Measure: 
● Search/query latency 
● Recall@5 
● Number of vectors examined per query 
4. Report average latency across the query set. 
Module 3: ANN Search Experiment — 3 Marks 
Task 5: HNSW vs IVF — 2 Marks 
1.Implement at least two ANN approaches: 
● HNSW 
● IVF 
2. Use the same embedding vectors and query set for both approaches. 
● For HNSW, vary at least one relevant search parameter. 
● For IVF, vary nprobe across at least three values. 
3.Measure for each configuration: 
● Recall@5 
● Average query latency 
● Search speed relative to exact search 
● Number/fraction of candidate vectors examined, where measurable 
Task 6: ANN Trade-off Analysis — 1 Marks 
1. Create at least two plots: 
1. Recall@5 vs Query Latency 
2. Recall@5 vs Search Efficiency 
2. Identify: 
● Fastest configuration 
● Highest-recall configuration 
● Best balanced configuration 
3. If this retrieval system had to serve a large number of queries, which ANN 
configuration would you select and why? Your answer must be supported by the 
experimental results. 
Module 4: Embedding Quality Analysis — 3 Marks 
Task 7: Qualitative Retrieval Analysis — 2 Marks 
1.Select 10 representative queries and compare the Top-5 results produced by: 
● Embedding Model 1 
● Embedding Model 2 
2.Identify at least three types of retrieval differences, such as: 
● Semantic similarity 
● Keyword overlap 
● Domain-specific terminology 
● Ambiguous queries 
● Short queries 
● Long queries 
3. Provide examples and explain why the models may produce different rankings. 
Task 8: Final Recommendation — 1 Marks 
Prepare a concise recommendation covering: 
1. Which embedding model performed better? 
2. Which similarity metric was most appropriate? 
3. Which ANN method provided the best trade-off? 
4. What configuration would you select for a resource-constrained deployment? 
5. What would be the main limitation of your chosen approach? 
6. How would you deploy one of the selected models in production? 
Recommendations must be based on experimental evidence rather than general 
statements.
